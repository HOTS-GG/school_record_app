# 생기부ON v1.2.0 패치노트

v1.1.4 → v1.2.0 (2026-09-08)

이번 버전은 화면 구성과 AI 지침 구조를 크게 손본 마이너 업데이트입니다. 데이터 구조(DB v13)는 v1.1.4와 동일하며 별도 마이그레이션 없이 그대로 열립니다.

---

## 새로운 기능

### 작성 도우미
- 생기부 작성 화면 오른쪽 아래에 **작성 도우미** 버튼이 생겼습니다. 어휘·표현·문장 다듬기 질문을 바로 할 수 있습니다.
- 셀 안에서 마우스로 문장을 **드래그해 선택한 상태로 질문**하면 그 문장을 대상으로 답합니다.
- 답변에서 굵게 표시된 표현을 **클릭하면 셀의 커서 위치에 바로 삽입**됩니다. `Ctrl+Z`로 되돌릴 수 있고 자동 저장도 정상 동작합니다. (셀을 편집 중이 아닐 때는 클립보드에 복사)
- 학생 이름 · 영역 · 활동 맥락이 자동으로 함께 전달됩니다.

### 학생 관리 화면 개편
- 왼쪽에 **학년 → 반 목록**이 표시되고, 반을 클릭하면 그 반 학생만 오른쪽 표에 나옵니다. 더 이상 전체 학생을 스크롤로 훑지 않아도 됩니다.
- 학생을 추가·수정하면 해당 반이 자동으로 선택됩니다.

### 영역 추가 시 권장 지침 자동 입력
- 영역 추가에서 `자율활동`, `진로활동`, `행동특성및종합의견`, `창체동아리`, `자율동아리`, `과목별세부능력특기사항` 이름을 입력하면 **영역별 AI 지침이 자동으로 채워집니다.** 직접 고친 내용은 덮어쓰지 않습니다.
- 기본 영역 추가(담임/교과)로 만든 영역에도 처음부터 지침이 들어갑니다.

### AI 생성 모달
- **전송된 프롬프트 보기** 버튼으로 실제로 AI에 보낸 시스템 프롬프트와 요청 내용을 그대로 확인할 수 있습니다.
- 행동 프로필 / PDF 분석 반영 여부가 ON·OFF 패널로 표시됩니다.

### 생기부 작성 화면
- 셀 오른쪽 상단 버튼이 **복사 / 이력**으로 정리되었습니다. 복사하면 잠시 "복사됨"으로 바뀝니다.
- 툴바에 **셀높이 자동 / 셀높이 고정** 전환 버튼이 추가되었습니다. 고정으로 두면 셀이 일정한 높이로 촘촘하게 배치되어 한 화면에 더 많은 학생을 볼 수 있고, 선택은 설정에 기억됩니다.

## 화면 · 사용성 변경

### 새 창 디자인
- 윈도우 기본 제목 표시줄 대신 **앱 자체 타이틀바**를 사용합니다. 최소화 / 최대화 / 닫기 버튼은 오른쪽 위에 있고, 빈 곳을 끌어 창을 옮길 수 있습니다.
- **사이드바가 기본으로 접힌 상태**로 시작합니다. 타이틀바 왼쪽 로고 옆 버튼으로 펼치고 접습니다. 접힌 상태에서는 아이콘에 마우스를 올리면 이름이 나옵니다.
- 홈 화면에서는 타이틀바가 투명하게 배경 위에 얹힙니다. 팝업(모달)이 열리면 창 버튼만 남고 나머지는 흐려집니다.
- 다크 테마에서 창 테두리 색도 함께 어두워집니다.
- 앱 시작 로딩 화면이 흰 스피너 하나로 단순해졌습니다.

### 메뉴 정리
- 모든 화면과 메뉴에서 `한글(English)` 식 영어 병기를 없앴습니다.
- 사이드바 메뉴 이름: **학생 관리 / 영역 관리 / 활동 관리 / 생기부 작성 / 문장 정리 / 유의어 점검 / 맞춤법 검사 / 가져오기 / 내보내기 / 체크리스트**
- `AI 대화` 항목은 사이드바에서 제거했습니다. (작성 도우미로 대체, 기능은 추후 삭제 예정)
- `사용 설명서`는 사이드바 아래쪽(파일 경로 / 버전 관리 / 사용 설명서 / 설정)으로 이동했습니다.
- 사용 설명서에 PDF 분석, 작성 도우미, 학급 목록 관련 항목을 추가하고 문구를 현재 화면에 맞게 고쳤습니다.

### 영역 관리
- **권장 지침 채우기** 버튼을 없앴습니다. 위의 "영역 추가 시 자동 입력"으로 대체되었습니다.
- 영역 수정 창의 프롬프트 안내 문구를 실제 동작("전역 프롬프트에 덧붙여 적용")에 맞게 고쳤습니다.

## AI 지침 구조 재편

같은 설정이라도 v1.1.4와 생성 결과가 조금 달라질 수 있습니다. 구조를 바꾼 이유와 내용은 다음과 같습니다.

**이전(v1.1.4):** 전역 프롬프트 하나에 모든 영역의 작성 요령이 다 들어 있어, 어느 영역을 쓰든 같은 지침 덩어리가 통째로 전달되었습니다.

**지금(v1.2.0):** 지침이 범위별로 나뉘어 순서대로 전달됩니다.

```
[지침 우선순위]        ← 충돌 시 어느 지침이 이기는지
전역 프롬프트          ← 모든 영역 공통 규칙 (역할 · 문체 · 어휘 · 분량 관리 등)
[영역 추가 지침]       ← 영역 관리에서 설정한 영역별 지침
[활동 추가 지침]       ← 활동 관리에서 설정한 활동별 지침
[활동 내용/일정 메모]
[출력 형식]            ← 항상 마지막에 자동으로 붙음 (편집 불가)
```

- 전역 프롬프트는 공통 규칙만 담도록 다시 썼습니다. 설정에서 "기본값으로 초기화"를 누르면 새 전역 프롬프트가 들어갑니다.
- 영역별 작성 요령(예: 행동특성은 추천서 성격, 세특은 교과 사고력 중심)은 **영역 프롬프트**로 옮겼습니다.
- 출력 형식(한 문단, 종결 어미, 금지 표현 등)은 코드가 항상 마지막에 붙이므로 프롬프트를 아무리 수정해도 형식이 깨지지 않습니다.
- 요청 본문에는 `[작성 대상]`, `[기존 내용]`, `[학생 행동 프로필]`, `[학생 제출 자료 분석]`, `[교사 추가 요구사항]`, 분량 기준이 구분되어 들어갑니다.

### ⚠️ v1.1.4 이하에서 올리는 경우 확인할 것
- 이전 버전에서 만든 기본 영역은 **영역 프롬프트가 비어 있을 수 있습니다.** 이 상태면 전역 프롬프트에서 빠진 영역별 요령이 어디에도 없게 되어 결과 품질이 떨어질 수 있습니다.
- 영역 관리 → 각 영역 수정 창에서 프롬프트를 확인하고, 비어 있으면 영역을 삭제 후 같은 이름으로 다시 추가하거나(지침 자동 입력) 직접 입력해 주세요. 영역을 삭제해도 학생의 생기부 문장은 유지됩니다.
- 전역 프롬프트를 직접 수정해 쓰고 있었다면 그대로 유지됩니다. 새 구조를 쓰려면 설정에서 기본값으로 초기화한 뒤 필요한 부분만 다시 고쳐 주세요.

## 안정성 · 내부 변경
- 팝업이 열릴 때 저사양 PC에서 화면이 하얗게 되던 문제를 수정했습니다. (CSS `:has()` 기반 판정을 명시적 상태 관리로 교체)
- 팝업 중 타이틀바가 검게 남던 문제를 수정했습니다.
- 개발 중 Pinia 스토어 HMR로 상태가 어긋나던 문제를 UI 스토어에서 수정했습니다.
- 셀 높이 옵션 변경 시 모든 셀 높이를 다시 계산합니다.
- Tauri 창 권한 추가: 최소화 / 최대화 / 닫기 / 드래그 / 테마 설정.
- 새 Rust 커맨드: `ai_writing_assist`, `get_default_system_prompt`, `get_area_default_prompt`. 제거: `fill_area_default_prompts`.
- 영역 생성 시 지침이 비어 있고 기본 영역 이름이면 Rust 쪽에서 권장 지침을 기본값으로 저장합니다.
- 테스트 308개 통과.
