# 생기부ON v1.3.0 패치노트

v1.2.0 → v1.3.0

## 새로운 기능

### 자동 업데이트
- 프로그램을 켤 때 새 버전이 있는지 자동으로 확인합니다. 새 버전이 있으면 초기 화면에 **「새 버전이 있습니다」** 알림이 뜹니다.
- 알림의 **업데이트** → **지금 업데이트**를 누르면 내려받아 설치하고, 프로그램이 잠시 닫혔다가 다시 열립니다.
- 학생부 파일(.db)과 API 키 등 설정은 그대로 유지됩니다.
- **설정 → 프로그램 업데이트**에서 현재 버전을 보고 직접 확인할 수도 있습니다. 작업 중이라면 학생부 파일을 닫은 초기 화면에서 설치합니다.
- **무설치 버전**은 자동으로 설치되지 않습니다. 알림의 **내려받기 페이지 열기**로 새 버전을 받아 기존 실행 파일과 바꿔 주세요.

### 사용 설명서 개정
- 사용 설명서를 현재 화면에 맞게 다시 썼습니다. (13개 항목, 70여 개 문답)
- 작성 도우미, 영역별 AI 프롬프트, 지침 구조, 설정 화면, 프로그램 업데이트 안내를 새로 넣었습니다.
- AI 기능을 쓸 때 어떤 정보가 전송되는지 항목별로 정리했습니다.

## 알아 두기
- 이번 v1.3.0은 **직접 한 번 설치**해 주셔야 합니다. v1.2.0에는 업데이트 기능이 없기 때문입니다. 다음 버전부터는 자동으로 받을 수 있습니다.
- 데이터 구조는 v1.2.0과 같아 기존 학생부 파일을 그대로 열 수 있습니다.
