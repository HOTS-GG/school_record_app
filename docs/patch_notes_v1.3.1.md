# 생기부ON v1.3.1 패치노트

v1.3.0 → v1.3.1

## 고친 점

### AI 오류 메시지가 원인을 알려 줍니다
- AI 생성·작성 도우미·PDF 분석·AI 대화에서 가끔 **「응답 파싱 실패」**만 뜨고 이유를 알 수 없던 문제를 고쳤습니다.
- 이제 크레딧 부족, AI 서비스 일시 오류처럼 **실제 원인이 오류 메시지에 그대로 표시**됩니다.
- 일부 AI 모델이 보내는 다른 형식의 답변도 정상적으로 받아들입니다.

## 알아 두기
- v1.3.0을 쓰고 계시면 프로그램을 켤 때 **자동으로 업데이트 알림**이 뜹니다.
- 데이터 구조는 v1.3.0과 같아 기존 학생부 파일을 그대로 열 수 있습니다.
