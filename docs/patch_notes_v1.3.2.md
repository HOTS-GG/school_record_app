## 화면 다듬기

### 업데이트 창
- 내용이 창 가장자리에 붙어 보이던 여백을 바로잡았습니다.
- 버전 제목이 두 번 나오지 않게 하고, 목록 앞 점과 소제목 크기를 정리했습니다.
- 「지금 업데이트」 단추의 아이콘이 글자 위로 올라가던 문제를 고쳤습니다.

### 생기부 작성
- 두 줄짜리 문장인데도 칸 안에 스크롤바가 생기던 문제를 고쳤습니다.
- 맨 아래 학생의 칸이 오른쪽 아래 **작성 도우미** 단추에 가려지지 않습니다.
- 어두운 화면에서 **PDF 분석** 표시가 잘 보이도록 색을 바꿨습니다.

### 그 밖에
- 낱말 중간(「있습니/다」)에서 줄이 바뀌지 않도록 했습니다.
- 작성 도우미 답변의 제목·목록·구분선이 기호 그대로 보이지 않고 서식대로 표시됩니다.
- 문장 정리 규칙에서 `\` 가 ₩로 보이던 문제를 고치고, 공백은 ␣로 보이게 했습니다.
- 라이선스·비밀번호·버전 관리·변경 이력 창의 모양을 다른 창과 맞췄습니다.
- 아이콘이 있는 단추들이 아이콘과 글자를 한 줄에 표시합니다.
- 왼쪽 메뉴에 마우스를 올렸을 때 선택된 메뉴와 헷갈리지 않게 했습니다.
- 밝은 화면에서 체크리스트 입력칸이 어둡게 보이던 문제를 고쳤습니다.

## 알아 두기
